## 1. 問題

Mac mini 外接一台 Wokyis 5 吋 16:9 小螢幕（1280×720，以 1 倍縮放顯示，約 294 ppi）。這個密度下，macOS 預設 13 pt 的字只有約 1.1 mm 高，任何現成 App 放上去都看不清楚。

使用者想把這塊螢幕當「抬頭瞄一眼就懂」的系統狀態面板，最想看的是活動監視器「記憶體」分頁底部那一塊（壓力圖＋七個數字）。但活動監視器無法把記憶體區塊獨立出來：它的「視窗」選單只能拆出 CPU 使用率與歷史記錄，Dock 圖示也只能顯示 CPU、網路、磁碟。

## 2. 目標與非目標

### 目標

1. 在 Wokyis 上全螢幕常駐一塊**大字面板**，數字與活動監視器（AM）一致。
2. 不干擾 Wokyis 上的其他全螢幕 App（例如 Music），兩者能互相切換。
3. 資源占用低到可以一直開著。
4. 可以下載安裝，不需要自己建置。

### 非目標

- iPhone、Apple Watch 電量（公開 API 讀不到，只有系統「電池」小工具拿得到）。
- GPU、磁碟、能耗等 AM 其他分頁。
- 面板自己設定登入時自動啟動（使用者可用 macOS 登入項目）。
- 修改任何系統設定；需要 sudo、網路或第三方套件的做法。

## 3. 使用者與情境

- **主要使用者**：桌上有 Mac mini＋Wokyis 的開發者，主螢幕在工作，Wokyis 放旁邊當狀態燈。
- **情境 A**：跑大型編譯或開很多 App 時，瞄一眼記憶體壓力是不是轉黃、轉紅，swap 有沒有暴增。
- **情境 B**：想看 CPU 是否滿載、網路是否還在下載，不想切到活動監視器。
- **情境 C**：出門前確認 AirPods、鍵盤、軌跡板還有多少電。
- **情境 D**：Wokyis 平常放 Music 全螢幕，需要時切到面板再切回去。

## 7. 設計決策

| 決策 | 理由 |
|---|---|
| 原生 AppKit App，不用本機網頁 | 網頁讀不到 sysctl、IOKit、IOPS，還要另寫原生 helper 加 HTTP 服務；全螢幕共存問題仍在（README §6） |
| 自己畫字（CoreText／CoreGraphics），不用系統元件 | 才能精確控制 64 px 字高與逐區塊重畫，壓低 CPU |
| 記憶體公式反組譯 AM 與 sysmond 得出 | Apple 沒有公開算法，網路流傳的公式是反推的、準確度未經驗證（原始需求列為未解問題）；驗收要求差距 ≤ 0.2 GB（README §8.1） |
| 網路計數器改用 IFMIB 的 64 位元值 | 一般介面清單的計數器會截成 32 位元，大流量時會繞回 |
| 程式流量用 `nettop` 的差量模式，每 2 秒跑一個子程序 | 介面計數器分不出程式；快照相減會漏掉短連線；stdin 必須接 pipe，否則 `nettop` 空轉吃滿一顆核心（README §8.8） |
| 數字每秒重畫 2 次，取樣仍每秒 4 次 | 每秒重畫 4 次時 CPU 曾超過 2%；壓力圖仍用每秒 4 次的取樣 |
| Carbon 全域快捷鍵 | 不需要「輔助使用」權限 |
| 單一實例用檔案鎖，不靠 pid 檔或 App 清單 | 不受 log 位置影響；兩份同時啟動也不會都退出；程式當掉時由系統自動釋放 |
| icon 的彩虹標籤用六色條紋，不用蘋果形狀 | 彩虹蘋果是 Apple 的註冊商標，repo 是公開的 |
| ad-hoc 簽章、不公證 | 沒有 Apple Developer ID；首次開啟由使用者在「隱私權與安全性」允許 |

## 8. 相依與風險

| 項目 | 風險 | 緩解 |
|---|---|---|
| 私有 API（`IOPSCopyPowerSourcesByType` 等） | 系統更新後可能消失 | 以 `dlsym` 取得，取不到時改用 `system_profiler` 或顯示「—」，不崩潰 |
| `nettop` 的輸出格式與私有符號 `responsibility_get_pid_responsible_for_pid` | 系統更新後欄位或符號可能改變 | 欄位依標頭名稱定位；解析不到就顯示「—」並寫 `ERR`；符號取不到時改顯示執行檔名稱 |
| AM 公式 | macOS 更新可能改變 AM 算法 | 內建 host_statistics64 稽核；`tools/amcompare` 可重跑比對 |
| CPU 餘裕 | 新功能可能讓 CPU 超過 2% | 量測工具 `tools/c7_measure.sh`；可再把數字重畫降到每秒 1 次 |
| 快捷鍵衝突 | 無法在執行期偵測 | 註冊結果寫進 log；可用 `--hotkeys no` 關閉 |
| 只支援 Apple Silicon、macOS 14 以上 | Intel Mac 無法使用 | 在需求與 release notes 中註明 |

## 10. 未決事項與後續可能

- 下載後首次開啟的 Gatekeeper 流程尚未實際走過一次，macOS 14 的介面字樣也未驗證。
- 以 Developer ID 簽章並公證，省去首次開啟的手動允許。
- CPU 量測補到每種條件至少 3 輪，並和 v1 交替比較。
- 快捷鍵可自訂，以支援非 US 鍵盤配置。
- 實機補量 AirPods 三格版面、個位數電量與低電量反白的字高。
