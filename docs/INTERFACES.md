# WokyisPanel — module interfaces and file ownership

Binding spec: `phase2/final/spec.md` (§4 signatures). This file records the **exact** signatures that exist in the
skeleton today, the extensions to §4 that the skeleton made, and who owns which file. Parallel agents edit only their
own files; a signature change that crosses an ownership line must be agreed with the lead and reflected here.

Build: `scripts/build.sh` (owner: core) compiles an explicit list — every file below already exists and compiles.
**Adding a new Swift file to the app requires a build.sh edit — ask the lead/core owner**; prefer adding code to your
existing files. `scripts/build.sh` runs `--selftest` (non-zero fails the build) and then `tools/build.sh`.
Swift 5 language mode (`-swift-version 5`), target arm64-apple-macos14.0, `-O`, frameworks AppKit/IOKit/CoreText/Carbon
(CryptoKit, ImageIO, UniformTypeIdentifiers autolink). One module, so every type below is visible everywhere.

**v2 (spec r2, `scratchpad/v2/design/spec.md`)**: the v2 ownership table, the shared v2 types and the stub interfaces
are in [§ v2](#v2-spec-r2--ownership-shared-types-interfaces) right below; the v1 table that follows is kept for history
(where the two disagree, § v2 wins).

### System (sampler; spec §5, implemented)

```swift
// SystemSampler.swift — sysQ (serial .utility), one-shot timer re-armed at every whole wall second (+0 ms, leeway 20 ms,
// MemorySampler.nextBoundary(period: 1)); runs whatever view is visible.
final class SystemSampler: @unchecked Sendable {
    init(injector: Injector, log: EventLog, onSample: @escaping @Sendable (SysSample) -> Void)   // onSample on MAIN
    func start(); func stop()                 // stop: no onSample after return (main-side delivery gate); not on sysQ
    func sampleNow(reason: String)            // "wake" resets both baselines → that sample only re-establishes them
    func stats() -> (samples: UInt64, durP99Us: Int?)   // HEALTH sys_dur_us_p99 (last 240 ticks)
}
// Display strings for StateBuilder (AM-identical; used by StateBuilder.cpu / .net):
enum SysFormat {
    static func percent(_ v: Double) -> String            // "4.99%" (L10n.fmt2, half-up; 99.995 → "100.00%")
    static func count(_ n: UInt64) -> String              // "4,783"
    static func perSecond(_ v: Double) -> String          // packets/s, rounded half away from zero, grouped
    static func speed(_ bytesPerSecond: Double, _ lang: Lang) -> String   // L10n.speed (bits, "/s" | "/秒", 1000.00 → next unit)
    static func file(_ bytes: UInt64) -> String           // ByteCountFormatter .file ("22.76 GB"; follows the system region)
    static func cpu(_ c: CPUReading?, tasks: TaskCounts?) -> CPUDisplay   // nil → "—"; threads nil (fallback) → "—"
    static func net(_ n: NetReading?, _ lang: Lang) -> NetDisplay          // nil → all "—"; nil rates → the 4 rate cells "—"
}
// Test seams (SystemSelfTest): SysEngine.tick(_ readers: SysReaders, inject: SysInject, simActive:, tWall:) -> SysSample,
// SysInject(Injector.Snapshot) (reads snapshot.fail / .garbage for cpu.load, cpu.tasks, net.if directly),
// CPUSource.swift: CPUTicks, CPUFormula.average / tasksPlausible, CPUDelta.feed, CPUReader (cached host + pset ports);
// NetSource.swift: IfCounters, NetFilter.included, NetDelta.feed, NetReader (IFMIB_IFDATA).

// MemorySampler (Sources/Memory/MemorySampler.swift), spec §5.4:
func setHz(_ hz: Double)          // memQ async; recomputes auditEvery (auditHz 0 → off), clamps ticksSinceAudit, re-grids
func currentHz() -> Double        // the sampler's own rate; not on memQ. HEALTH mem_hz= prints AppController.memHz instead
                                  // (the rate last REQUESTED via setHz), not this value
static func auditEvery(hz: Double, auditHz: Double) -> Int
static func retune(hz: Double, auditHz: Double, ticksSinceAudit: Int) -> (auditEvery: Int, ticksSinceAudit: Int)
```

Result states per tick (SysSample): `cpu` `.value` | `.skipped(baseline|dt_short|no_ticks|cores_changed|gap|garbage)` |
`.failed(injected|kr=N)`; `tasks` `.value(TaskCounts)` (threads nil = proc_listallpids fallback after pset kr≠0) |
`.failed(injected|implausible|kr=N)`; `net` `.value(NetReading)` (rates nil on the first read / after a reset or a > 5 s
gap) | `.skipped(dt_short)` | `.failed(injected|errno=N|parse)`. A failed source clears its own baseline, so the first good
read after a failure is a baseline (no gap WARN). Simulated flags are per graph, like `MemSample.simulated` (pressure
only): `cpuSimulated` = fail/garbage `cpu.load`, `netSimulated` = fail/garbage `net.if` in this tick's snapshot
(`SysInject.cpuSeries` / `.netSeries`); a `cpu.tasks` injection marks neither (no graph plots the counts). Store.applySys
copies them into `CPUPoint.simulated` / `NetPoint.simulated` (the 7 px magenta stripe). Selftests `store.sim_per_graph`,
`sys.inject.fail_net`. The CPU / NET log `sim=` token is still the global "any injection active" flag.

Logs (all through `log.line` / `log.event`): `CPU` / `NET` every tick at sample level (format spec §9.1; `rx_bps` /
`tx_bps` are bytes/s); at summary level the sampler itself keeps one line per kind per `summarySeconds` and drops
`.skipped` lines (EventLog's own CPU/NET decimation agrees with it). `ERR src=cpu.load|cpu.tasks|net.if err=…` (event)
on onset / token change, `… repeat=1 n= for_s=` (line) every 60 s, `RECOVER src= failed_s= n=` (event). WARN (event, ≤ 1
per key per 60 s, `suppressed=N`): `cpu_cores_changed from= to=`, `cpu_delta_reset reason=gap|garbage …`,
`cpu_tasks_implausible threads= procs=`, `cpu_tasks_fallback err= procs=`, `net_counter_reset if= field= old= new=`,
`clock_step src=sys dir=back by_s= regrid=1`.

Self-test hook: `SystemSelfTest.run()` (called from `SelfTest.runAll`, one line): `cpu.formula.*`, `cpu.guards.*`,
`cpu.tasks_plausible`, `net.filter`, `net.rates.*`, `sys.engine.normal`, `sys.inject.*`, `sys.real_errors`,
`sys.err_repeat`, `sys.log.*`, `sys.fmt.*`, `fmt.file`, `sampler.set_hz`, `sys.live_read`, `sys.ports_stable`.
